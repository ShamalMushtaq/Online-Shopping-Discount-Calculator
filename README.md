Online Shopping Discount Calculator

Description:
This is a simple Python program that calculates the final amount of an online shopping purchase based on the shopping amount and Premium Membership status.

Features:
1. Takes the total shopping amount from the user.
2. Checks whether the customer is a Premium Member.
3. Calculates regular discount using if-elif-else.
4. Provides an additional 5% discount to Premium Members using a nested if.
5. Calculates the total discount.
6. Displays the final amount to pay.

Discount Rules:

Shopping Amount	Discount
Rs. 10,000 or above	20%
Rs. 5,000 – 9,999	10%
Rs. 2,000 – 4,999	5%
Below Rs. 2,000	No discount

Premium Member:	Additional 5%

Technologies Used:
Python 3
if-elif-else
Nested if
User Input
Basic Arithmetic Operations
