🛒 Online Shopping Discount Calculator

📌 Description:
This is a simple Python program that calculates the final amount of an online shopping purchase based on the shopping amount and Premium Membership status.
The program uses if-elif-else statements to calculate the regular discount and a nested if statement to provide an additional discount to Premium Members.

✨ Features:
🛍️ Takes the total shopping amount from the user.
👑 Checks whether the customer is a Premium Member.
💰 Calculates the regular discount using if-elif-else.
🎁 Provides an additional 5% discount to Premium Members.
🧮 Calculates the total discount.
💵 Calculates and displays the final amount to pay.

💸 Discount Rules:

Shopping Amount	Regular Discount
Rs. 10,000 or above	20%
Rs. 5,000 – Rs. 9,999	10%
Rs. 2,000 – Rs. 4,999	5%
Below Rs. 2,000	No Discount
👑 Premium Member Discount

Premium Members receive an additional 5% discount.

🛠️ Technologies Used:
🐍 Python 3
if-elif-else
Nested if statement
User Input
Basic Arithmetic Operations

▶️ How It Works:
The user enters the total shopping amount.
The program asks whether the customer is a Premium Member.
The regular discount is calculated according to the shopping amount.
If the customer is a Premium Member, an additional 5% discount is applied.
The program calculates the total discount.
The final amount to pay is displayed.

Example:

Input:
Enter total shopping amount: Rs. 12000
Are you a Premium Member? (Yes/No): Yes

Output:

----- Shopping Bill -----
Original Shopping Amount: Rs. 12000
Regular Discount: Rs. 2400
Premium Discount: Rs. 600
Total Discount: Rs. 3000
Final Amount to Pay: Rs. 9000
